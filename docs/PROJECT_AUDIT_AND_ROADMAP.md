# AI漫剧制作大师：全项目验收清单与功能路线图

更新日期：2026-11-18
仓库：Qazwesrd/AI-

## 1. 产品目标（必须保留）

- Windows 本地桌面应用；Electron + Next.js + FastAPI + SQLite + FFmpeg。
- 小说/文章导入支持 TXT、MD、DOCX、EPUB、可提取文本的 PDF、RTF；旧版 DOC 需要转换。扫描版 PDF 的 OCR 仍属于待增加能力。
- AI 深度解析章节、人物、人物关系、事件、时间线、地点、场景、道具、武器、服装、建筑和特殊物品；识别结果先由用户确认，再进入正式素材库。
- 为人物、场景、道具等生成视觉参考和三视图；风格包含真人电影、3D动漫电影、2D动漫、国风漫画、水墨动画和自定义参考图。
- 按原著剧情完整性将一个章节改编成一集或两集，不机械按字数切分；每集目标约 120 秒，允许 90–150 秒；用户可合并、拆分、排序。
- AI 生成剧本、分镜、视频片段、角色配音、字幕和配乐，最终合成漫剧。
- 独立的视频剪辑功能不受漫剧 90–150 秒时长限制。
- 大文件上传支持最大 2 GB；本地优先，支持后续备份。
- 22 个发布平台：国内 12 个、海外 10 个。只有具备官方 OAuth/API 的平台才能启用自动发布；其他平台必须明确显示为人工发布辅助。
- AI 网络调用必须受总开关控制；付费模型需独立总授权和每次调用确认；不自动购买或充值；未知费用按付费处理；密钥加密保存，不返回明文。
- 保护用户现有 AppData 数据库和小说数据，不得用测试数据库覆盖真实数据库。

## 2. 当前代码检查已确认

- GitHub Actions 已通过后端 Python 编译、9 个路由导入、前端 TypeScript 和 Next.js 生产构建（提交 5fbd67e）。
- 后端当前注册的核心路由包含小说、AI 管理、视觉素材、剧本分镜、媒体生产、视频剪辑、AI 小说分析、发布及发布上传。
- 已有分批分集规划、剧本与分镜生成、视频任务持久化、批量任务、任务刷新、FFmpeg 合成、语音轨和 SRT 字幕流程。
- 发布中心当前覆盖 22 个平台，但平台列表均为人工发布模式；不能宣传为 22 平台自动发布。
- 视频服务商配置仍是可配置 API 路径/字段的通用方式，尚未实现各家服务商专属的参考图上传与图生视频适配。
- Windows 安装包仍需在真实 Windows 环境重建、启动、关闭、升级和数据库保留测试。

## 3. 本轮修复与回归检查

- 统一素材库同时读取用户上传素材、AI/视频处理生成媒体和角色/场景/道具视觉资产；视觉资产跳转到视觉工作室管理，避免误删核心角色设定；不同来源使用不同删除接口，避免 ID 冲突。
- 长篇小说章节目录只查询章节元数据，正文在用户打开单章时才加载，避免一次传输 886 章全文。
- 媒体上传采用临时文件写入后原子替换，失败时清理临时文件并回滚数据库。
- 新增媒体文件安全下载和删除接口；下载/删除均限定在应用 storage 目录内。
- 增加文档导入与章节切分回归测试：UTF-8 BOM、GB18030、中文章节、英文 Chapter、DOCX、EPUB、空文件和不支持格式。
- 大型小说导入接口不再一次性回传所有章节正文；重新导入前增加替换确认，并将旧剧本项目标记为 source_changed，保留旧剧本供复核。
- 配音时间轴优先读取实际视频片段时长；对白超过镜头时长 1.5 倍时不再静默截断或自动重复付费生成。
- React/React DOM 更新至 19.3.1，CI 增加生产依赖高危漏洞审计，并启用 Dependabot 定期依赖更新。
- CI 增加独立临时数据目录下的数据库初始化测试；不会触碰用户真实数据库。

## 4. 仍需完成的缺陷与验收项（按优先级）

### P0：核心生产链路
1. 建立数据库版本迁移系统（Alembic 或等效方案）：启动时检测版本、迁移前自动备份、失败回滚；禁止用 create_all 代替既有表结构升级，禁止覆盖用户数据库。
2. 为主流视频生成服务商实现独立 adapter：认证、图片上传、图生视频字段、异步任务创建、状态查询、失败码映射、下载；每家接口必须按官方文档验证，不能臆造统一字段。
2. 将已确认的角色三视图、场景图和道具图真正传入视频生成任务；支持参考图权重/首尾帧/角色参考等平台能力。
3. 以实际视频片段时长作为配音与字幕时间轴基准；TTS 超时不得直接截断整句，应按镜头时长调整语速或提示用户扩展镜头。
4. 对 90–150 秒成片执行真实时长、音画流、编码、黑帧/静音和文件完整性检查；失败可定位到镜头并单独重试。
5. 长篇小说解析、分集、镜头生成、图像和视频任务必须支持暂停、继续、断点恢复、重试、进度、错误明细和幂等，避免重复扣费。

### P1：素材一致性和创作质量
1. 角色视觉圣经：脸型、年龄阶段、发型、服装版本、体型、颜色、标志物、声音、参考图和负面提示词锁定。
2. 场景/道具连续性：空间位置、昼夜天气、损坏状态、持有者、首次出现章节和剧情状态。
3. 章节—事件—剧本—分镜—素材—视频镜头建立可追溯关联，支持原著覆盖率和剧情遗漏检查。
4. 分镜可视化编辑：拖拽排序、镜头时长、台词、运镜、参考图、提示词和镜头替换。
5. 生成素材版本管理、收藏、标签、重复文件识别和项目级复用。

### P1：本地桌面可靠性
1. 首次启动检测数据库、端口、FFmpeg/FFprobe、模型目录和磁盘空间；提供可读诊断日志。
2. 安装升级不得覆盖 AppData 数据；提供一键备份/恢复和导出项目包。
3. 避免固定端口冲突；支持自动寻找可用端口并把实际 API 地址传给前端。
4. 任务运行时防止关闭窗口造成任务丢失；支持后台运行、退出确认和异常恢复。
5. 真实 Windows 验收：全新安装、旧版本升级、断网启动、重启恢复、超大文件、路径含中文、空格和非管理员权限。

### P2：扩展功能建议
1. 扫描 PDF OCR：可选本地 OCR 引擎，默认不上传原文。
2. 角色配音管理：角色声线映射、语速/情绪、批量配音和音色试听。
3. 口型同步：按对白生成口型/表情驱动；作为可选步骤，不强制增加成本。
4. 智能配乐与音效：按剧情情绪、镜头动作自动建议，用户确认后合成。
5. 多比例自动适配：16:9、9:16、1:1、2.35:1；按平台安全区重新排版字幕和主体。
6. 预算中心：调用前估算、单次/单集/项目预算上限、实时消耗和停止阈值；未返回价格时默认阻止付费调用。
7. 一键项目归档：原著、解析、剧本、分镜、素材、提示词、视频、字幕和生成参数打包导出。
8. 发布素材预检：各平台时长、分辨率、封面比例、标题/标签长度和版权提示检查。

## 5. 验收原则

- “代码已提交”“CI 编译通过”“接口可启动”“服务商真实调用成功”“Windows 安装包实机通过”是不同等级，必须分开报告。
- 未获得平台官方 API 文档、凭证和真实测试结果前，不得标记为自动发布或图生视频已完成。
- 任何数据库迁移必须先备份、可回滚；不得删除或重建用户现有小说数据。
- 所有新增付费 AI 操作必须经过用户主动触发、全局网络开关、付费总授权和单次确认。


## 6. 统一开发阶段新增能力（待统一验收）

- 项目级归档导出：新增 `POST /api/story/projects/{project_id}/export` 创建归档，随后通过 `GET /api/story/projects/{project_id}/exports/{filename}/download` 流式下载；`GET /api/story/projects/{project_id}/exports` 列出该项目的归档，导出所选剧本项目、原著章节、分集、分镜、视觉素材、剪辑时间轴及已关联的本地媒体文件；生成 manifest 和逐文件 SHA-256；拒绝素材目录外路径；不包含服务商密钥、本地加密密钥或整个工作空间数据库。
- 项目归档前检查：限制关联素材文件数、总字节数和结构化 JSON 大小；预检目标磁盘空间；归档写入临时文件，完成 ZIP CRC 检查后原子替换。
- 完整生产链路检查：新增 `GET /api/story/projects/{project_id}/production-readiness`，只读检查原著章节覆盖、分集剧本、分镜字段、视觉素材引用、镜头视频关联、逐集最终合成视频、配音轨、音乐音效和字幕线索；不联网、不调用 AI、不自动生成。
- 分集工作台增加“导出完整项目包”和“检查完整生产链路”入口，并显示归档素材数、缺失引用、生产阻断项和人工复核提醒。
- 以上能力已加入统一开发分支，自动化测试和 Windows 桌面端实机验证尚待最终统一验收；不得提前视为正式版已交付。
