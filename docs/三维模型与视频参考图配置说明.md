# 三维模型与视频参考图配置说明

本文说明如何在 AI 漫剧制作大师中启用真实 GLB 三维模型生成，以及如何把已确认视觉素材作为视频生成参考图。

## 一、配置 Tripo 三维模型服务

1. 打开「AI 创作中心 / AI 模型管理中心」。
2. 在服务商列表选择「Tripo AI 三维模型」。
3. API 地址保持为 `https://openapi.tripo3d.ai/v3`。
4. 模型默认使用 `v3.1-20260211`。
5. 在 Tripo 官方控制台创建 API Key，粘贴到密钥栏。
6. 保持「此服务商/当前模型属于付费服务」勾选，除非你已核实账户实际计费规则。
7. 启用服务商并保存。执行前还必须打开网络调用总开关；付费 API 总授权与单次确认仍然独立生效。

官方 API 文档：
- https://developers.tripo3d.ai/en/docs/introduction
- https://developers.tripo3d.ai/en/docs/generation-multiview-to-model/standard
- https://developers.tripo3d.ai/en/docs/files

## 二、生成 GLB 模型

1. 打开「视觉素材工作室」，先同步或创建人物、场景、道具等素材。
2. 检查外观、服装、材质、固定特征，确认素材。
3. 点击「创建多视角任务」。
4. 在图片生成任务队列中，逐项点击「执行生成」，完成正面、侧面、背面（场景为广角、侧向、俯视等）参考图。图片生成仍受图像服务商配置和付费确认控制。
5. 素材卡片中勾选「确认本次 3D 生成可能收费」，点击「生成真实3D模型（Tripo）」。
6. 点击「查询/下载3D模型」刷新任务。完成后会下载 GLB 到本地视觉素材目录。
7. 点击「下载 GLB 模型」可保存模型文件，供 Blender、Unity、Unreal Engine 或其他兼容工具继续编辑。

系统会将远程任务 ID、模型版本、输入视角、进度、GLB 路径和预览信息记录在对应素材档案中。同一素材已有进行中的任务时会复用现有任务，避免重复提交。

注意：
- 至少需要正面图，以及侧面或背面中的另一张图；三张视图效果更好。
- 输入图片应是同一主体、清晰、无遮挡、光照尽量一致的视图。
- 当前集成输出 GLB；普通二维三视图图片本身不是三维网格。
- Tripo 账户额度和收费规则以服务商控制台为准；本软件不会自动购买或充值。

## 三、分镜视频参考图

在「剧本改编与智能分镜中心」的「分镜视频生成配置」中：

1. 先完成视频服务商配置，确认该服务商支持图像参考输入。
2. 默认「关闭参考图（纯文字提示词）」。
3. 只有当服务商文档明确支持 JSON Base64 Data URI 图片输入时，才选择「发送已关联素材图片（Data URI）」。
4. 按服务商接口文档填写图片字段，例如 `image`、`image_url` 或嵌套字段 `input.image`。
5. 将已确认的人物、场景或道具关联到具体分镜，再提交视频生成任务。

每个镜头最多自动选择一张已关联参考图，优先人物，其次场景、武器和道具；图片上限 8 MB，支持 PNG、JPEG、WEBP。图片直接随请求发送，不会自动上传到第三方图床。

**重要：** 不同视频服务商的字段名、图片输入方式和请求结构并不统一。不要仅因为某接口支持视频生成就开启参考图模式；若其只支持公开 URL、multipart 上传或专用文件 ID，应保持关闭，后续需要为该服务商增加专用适配器。纯文生视频服务商继续使用默认关闭模式即可。
