# AI 网页工具协同中心：第三阶段

## 内嵌网页浏览器与自动下载归档

- Electron 桌面版通过独立 BrowserWindow 打开配置的 AI 网站，不再强制跳转系统默认浏览器。
- 浏览器使用持久化 Electron session partition（`persist:ai-web-tools`），网站登录状态可跨任务保留。
- 打开浏览器时将当前任务 ID 绑定到该浏览器窗口。
- 浏览器下载事件按窗口所属任务归档，支持图片、视频、音频和常见文档扩展名。
- 文件直接写入应用数据目录下的 `storage/web_ai_results`，再调用本地 API 登记元数据。
- 前端接收下载完成事件并即时刷新对应任务文件列表。
- 单文件限制 2 GB；超出限制会取消下载；未知扩展名会拒绝自动归档。
- 如果文件已下载但登记 API 失败，文件保留在本地并显示提示，用户仍可通过手动导入恢复。

## 安全边界

- 仅允许 HTTP/HTTPS 网站。
- 不读取或导出第三方 Cookie、密码、令牌。
- 不绕过验证码、登录墙、订阅墙或网站访问控制。
- 不自动提交提示词或触发付费生成；用户仍在网页中操作和确认。
- 持久化登录会话保存在 Electron 管理的应用 session partition 中。
- 网页内容属于不可信输入；浏览器与主应用保持 context isolation、关闭 Node integration 和 sandbox。

## 当前不包含

- 自动识别第三方网页页面中的生成状态或结果内容。
- 对所有网站通用的自动粘贴、自动点击生成按钮。
- 对第三方站点 DOM 或私有接口的抓取。
- 自动把媒体内容进一步拆分成角色、场景、道具或镜头实体；当前自动归档到发起任务，后续阶段再做内容识别与实体关联。
