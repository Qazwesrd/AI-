# AI 漫剧制作大师：简明操作流程与项目验收清单

> 目标：让第一次使用的人也能按顺序完成“小说 → 分析 → 视觉素材 → 剧本分镜 → 视频成片 → 质检发布”。建议始终以一个项目为单位操作。

## 项目统一工作台

从首页点击“打开项目工作台”或左侧“统一项目工作台”，选择小说后即可集中查看：
- 小说章节数、字数和分析条目/确认数量；
- 当前小说关联的改编项目、分集、镜头和视觉素材；
- 视频任务完成情况、统一任务中心状态和发布统计；
- 六阶段创作入口及当前阶段建议的下一步。

工作台会将当前小说编号和改编项目编号保存在页面地址中。复制地址或刷新页面时，可恢复对应的项目选择。工作台只汇总数据，不会自动触发 AI 请求、图片/视频生成、付费任务或发布操作。

### 当前项目的任务追踪

在工作台选择改编项目后，任务统计和最近任务会按该项目筛选。点击“打开当前项目任务”，任务中心会自动选中对应项目。任务中心也可以切换“全部项目”或其他改编项目，并继续按模块、状态和关键词筛选。

- 视频/配音任务按分集所属改编项目归类；
- 视觉生成任务按素材与项目的关联记录归类；
- 小说分析任务按所属小说归类，因此同一小说的多个改编版本会看到同一份小说级分析任务；
- 没有关联到所选项目的独立任务不会被错误归入该项目。

项目筛选只影响任务列表与统计展示，不会更改任务状态或触发 AI、视频、配音等调用。

### 人物、场景与道具的视觉连续性检查

在分镜中心的分集卡片中点击“检查视觉一致性”，可对当前分集执行本地规则检查：

- 镜头是否关联视觉素材；填写了场景名称时是否关联场景素材；
- 人物、场景、武器、服装、建筑等关联角色与素材分类是否匹配；
- 素材是否已经人工确认；
- 素材是否属于当前小说；
- 分镜关联是否保存剧情状态快照；
- 素材后续章节是否发生变化，而当前镜头仍锁定较早版本。

存在跨小说素材或角色/分类错误时，视频生成和成片合成会被阻止；缺少素材、未确认素材、较新剧情状态等情况会作为提醒，用户可先检查并修正。检查只读取本地数据库，不调用 AI，也不会自动替换素材。

视觉素材的剧情变化记录支持外观、服装、年龄、发型、伤势、装备、道具状态、持有人和原文依据。新增变化时需要明确选择是否确认；未确认的变化不会覆盖当前有效状态。

### 配音、混音与成片音频质量检查

- 分镜配音按镜头时间线拼接；无对白镜头补静音，保持整集时间线连续。
- 合成对白、原始镜头声音和背景音乐时，执行响度标准化与峰值限制，降低混音过响和削波风险。
- 发布中心的“扫描黑屏与静音”额外检测音频平均音量和峰值，提示音量过低或削波风险。
- 音频检测结果仅作人工复核建议，不会自动改变原音轨或强制放大声音；用户可决定是否重新混音。
- 字幕按分镜顺序生成时间轴，每条对白字幕覆盖对应镜头时间段，字幕文件单独保存，便于人工校对和后续编辑。

## 一、最简单的创作流程

### 第 1 步：新建项目并导入小说
1. 从首页点击“导入小说”，进入小说与项目管理。
2. 新建项目，填写项目名称。
3. 导入 TXT 或粘贴文本；检查章节是否完整、顺序是否正确。
4. 打开项目，确认当前小说和章节无误。

**完成标准：** 项目存在，小说正文可查看，章节数量和顺序正确。

### 第 2 步：分析剧情与世界观
1. 进入“小说深度分析与剧情审核”。
2. 选择当前项目和小说。
3. 选择需要分析的内容范围，检查分析任务预计使用的服务与费用。
4. 只有在确认服务可用、价格和额度清楚后，才手动发起 AI 请求。
5. 检查人物、关系、场景、道具、事件、故事线和世界观结果。
6. 修正错误、合并重复项，再确认可用于后续创作的结果。

**完成标准：** 分析结果属于正确项目，关键人物和剧情事件经人工核对。

### 第 3 步：确认视觉素材
1. 进入视觉工作室，选择当前项目。
2. 先确认主要人物，再确认常用场景和关键道具。
3. 为主要人物建立统一外观基准；需要时补充三视图、服装和状态变化。
4. 检查图片、提示词和素材归属，标记确认版本。
5. 对不准确的素材先修改，再用于分镜。

**完成标准：** 主要人物、场景和关键道具有可用素材，素材归属与版本明确。

### 第 4 步：改编剧本并制作分镜
1. 进入剧本与分镜，选择同一个项目。
2. 按章节建立分集草案，调整每集内容和顺序。
3. 逐集生成或编辑剧本，核对原著关键情节、人物动机和对白。
4. 把每段剧情拆分为镜头，填写景别、运镜、动作、对白、环境和时长。
5. 将镜头关联到已确认的人物、场景和道具素材。
6. 检查每集总时长和剧情衔接；目标单集约 90–150 秒时，应按内容调整镜头数量与节奏。

**完成标准：** 每集有可读剧本和分镜；关键镜头关联了正确素材；没有明显剧情断层。

### 第 5 步：生成视频、配音并合成
1. 先在 AI 管理中心核对服务商、模型、网络权限、免费额度和计费方式。
2. 在分镜中心检查镜头提示词和参考素材；确认服务商接口确实支持当前输入格式。
3. 逐批提交视频任务，观察任务中心状态；对“提交结果未知”的任务先去服务商侧核实，不要盲目重复提交。
4. 检查视频结果后，再生成配音或导入已有音频。
5. 需要时添加字幕、背景音乐和音效。
6. 按集合成视频，确认文件存在、可播放、时长和画面声音正常。

**完成标准：** 每集有可播放的本地成片；视频、音频和字幕均与分镜一致。

### 第 6 步：质检并准备发布
1. 检查视频完整性、黑帧、静音、音画同步、字幕错字和片尾。
2. 保存质检结果；有问题先回到对应镜头或剪辑步骤修复。
3. 从分镜成片入口把视频交给发布中心，或在发布中心手动选择视频文件。
4. 检查标题、封面、简介、标签和目标平台。
5. 确认平台账号授权和发布方式；由用户手动创建发布任务并决定是否执行。

**完成标准：** 成片通过检查，发布资料完整，发布动作经过用户明确确认。

## 二、遇到问题时按这个顺序处理

| 现象 | 建议操作 |
|---|---|
| 找不到项目或小说 | 回到项目管理，确认项目、小说和当前选择是否一致 |
| 分析结果为空 | 检查章节正文、任务状态和服务商配置；失败任务先查看错误详情 |
| 人物或场景素材不一致 | 回视觉工作室检查确认版本，再回分镜重新关联 |
| 镜头没有视频 | 在任务中心查看状态和错误；未知提交状态先核实服务商任务记录 |
| 视频已完成但本地文件不存在 | 检查下载状态、存储空间和网络，再使用任务提供的恢复操作 |
| 配音或字幕不正确 | 回到对应分集检查文本、声音配置和时间轴，再重新生成或替换 |
| 合成失败 | 检查输入文件、FFmpeg 环境、文件权限和磁盘空间 |
| 发布中心无法识别视频 | 确认文件在应用允许的素材存储目录中，再重新选择文件 |

## 三、费用与数据安全原则

- 默认先检查免费额度、计费单位、价格、额度有效期和服务商条款。
- 不允许自动充值、自动购买或在未知计费状态下自动发起调用。
- 付费 API、视频生成、配音和第三方上传必须由用户单独确认。
- 不要把 API 密钥写进代码、日志、截图或提交记录。
- “提交结果未知”时先查询服务商记录，避免重复扣费。
- 发布账号授权、上传和正式发布是不同动作，不能将它们混为一谈。

## 四、项目验收清单

### 创作流程
- [ ] 新建项目、导入小说、章节管理正常。
- [ ] 分析任务可以查看状态、错误和结果。
- [ ] 统一任务中心支持按改编项目筛选，工作台入口能带入当前项目。
- [ ] 人物、关系、场景、道具、事件和世界观结果可检查和修正。
- [ ] 视觉素材可生成、预览、确认和关联到镜头。
- [ ] 人物、场景、道具剧情变化支持确认状态和章节状态快照。
- [ ] 分集视觉一致性检查可发现缺失关联、素材分类错误、跨小说素材和过期状态。
- [ ] 存在视觉一致性错误时，视频生成与成片合成会被阻止。
- [ ] 配音按镜头时长拼接，字幕时间轴与镜头顺序一致。
- [ ] 成片混音执行响度标准化和峰值限制。
- [ ] 发布前可扫描音频平均音量、峰值、持续静音和黑屏。
- [ ] 分集、剧本、分镜可创建、编辑、排序和保存。
- [ ] 视频、配音、字幕和合成任务可追踪。
- [ ] 成片可播放、可检查、可重新处理。
- [ ] 发布中心能接收成片，但不会未经确认自动发布。

### 易用性与稳定性
- [ ] 每个页面明确显示当前项目和当前分集。
- [ ] 主要操作有清晰名称、必要说明和执行结果。
- [ ] 提交中有加载状态，防止重复点击和重复创建任务。
- [ ] 空数据、加载失败、网络中断和权限不足有明确提示及恢复入口。
- [ ] 关闭并重新打开项目后，能够找到已保存内容和任务记录。
- [ ] 备份、恢复、迁移和升级流程经过实际测试。

### 桌面端交付
- [ ] Windows 安装包可成功安装和卸载。
- [ ] 首次启动能完成必要初始化。
- [ ] 正常使用不需要用户分别手动启动前后端。
- [ ] 退出后再次启动，项目数据仍然存在。
- [ ] FFmpeg、数据库、存储目录和日志诊断可用。
- [ ] 安装包版本、校验和及发布产物可追溯。

## 五、建议的日常使用原则

**始终只选定一个项目，按六步顺序推进；每一步先检查结果再进入下一步。** 如果中途失败，优先从任务中心查看失败原因并恢复，不要直接重复提交可能收费的任务。


## 第十阶段：分集剪辑时间轴（新增）

在分集剪辑工作台（`/editing?episode_id=分集编号`）中，可以：

- 查看当前分集全部镜头，并上下调整镜头顺序；
- 为镜头之间设置直接切镜、淡入淡出或叠化，并设置转场时长；
- 设置片头标题、片尾标题；
- 设置背景音乐音量、淡入和淡出时长；
- 保存本地剪辑方案版本，重新打开后恢复。

剪辑方案会检查镜头是否完整、是否重复、是否错误引用其他分集镜头，以及转场类型和时长是否合法。原始分镜、原始视频和已有成片不会被覆盖；保存方案不调用 AI 或第三方服务。

**当前阶段边界：** 本阶段完成时间轴方案的持久化、编辑界面和 API 校验。转场、标题卡和音乐淡入淡出参数尚未接入最终 FFmpeg 成片渲染，因此保存方案不会改变已导出的成片。下一步需完成渲染器应用时间轴方案，并增加逐镜头替换后局部重渲染。


## 第十一阶段：时间轴实际渲染与单镜头替换（新增）

保存时间轴后，在分集剪辑工作台点击“按时间轴合成成片”，本地 FFmpeg 会应用：

- 已保存的镜头顺序；每个镜头仍使用其当前有效的视频素材；
- 直接切镜保持硬切，淡入淡出和叠化使用 FFmpeg xfade；
- 片头标题和片尾标题（需要本机可用的微软雅黑或 DejaVu Sans 字体）；
- 背景音乐音量、淡入和淡出；
- 按转场重叠时长修正对白字幕的时间轴；
- 导出后继续执行视频流、音频流和时长校验。

镜头卡片新增“导入本地视频替换此镜头”。替换素材仅保存为一条新的本地完成任务记录，旧任务和旧文件保留；重新合成时优先使用最新替换版本。支持 MP4、MOV、MKV、WebM，单个文件上限 1GB。该操作不调用 AI、不上传第三方、不产生 API 费用。

**操作顺序：** 先保存时间轴 → 如需替换则导入本地镜头 → 点击“按时间轴合成成片”。合成会生成新文件，不覆盖已有成片。当前单镜头替换要求用户提供已经制作好的视频文件；自动 AI 重生成仍须走原有授权和付费确认流程。
