# 《AI漫剧制作大师》正式版新增功能实施规格

> 状态：开发规格，待分阶段实现与验收。本文不代表下列功能已经在软件中完成。
> 目标分支：`offline-ai-engine-integration`
> 原则：离线优先、免费优先、用户确认优先、保护现有项目与模型数据。

## 1. 总体实施原则

- 不合并 PR #152；本阶段继续在其 Draft 开发线上推进，最终统一验收。
- 不删除、覆盖或迁移用户已有模型、素材、小说、项目、提示词和历史记录。
- 新增数据采用独立版本化目录/数据库表；首次升级前备份，升级失败可回滚。
- 默认本地运行；不调用付费 API、不自动购买、不擅自上传小说或素材。
- 需要联网的市场研究只读取允许公开访问的信息；尊重平台访问限制、robots、速率限制和平台条款。不能稳定获取的数据标记“暂无可靠数据”，不伪造热度。
- 任何平台自动发布仅限官方 API/授权集成；其余平台生成上传包并由用户手动完成。
- 所有自动化任务提供暂停、取消、断点续做、失败重试和日志。

## 2. 爆款研究与智能提示词中心

### 2.1 热门作品研究
- 支持国内外平台、地区、语言、题材、时间范围筛选。
- 记录来源平台、作品名称、作者/版权信息（可取得时）、采集时间、原始链接、榜单位置/公开指标、样本口径。
- 分析题材、开篇钩子、人物关系、冲突、反转、悬念、节奏、封面标题、视觉风格。
- 多来源交叉验证；区分单日热度、持续热度和真实可验证的播放/互动数据。
- 每条结论展示证据和可信度；来源不足时不得标记为“已确认爆款”。
- 不复制受版权保护作品的完整剧本、台词或画面；只提炼可归纳的创作规律。

### 2.2 提示词库
- 内置分类：小说分析、全书大纲、分集剧本、人物设定、场景设定、图片生成、分镜、视频生成、配音、字幕、剪辑、封面标题、多语言发行。
- 用户可自行新增任意数量提示词和分类，支持命名、备注、编辑、复制、标签、搜索、收藏、导入/导出。
- 本地保存，离线可访问；提示词含变量定义、适用模型/任务、版本号和创建/修改时间。
- 提供模板预览、复制、变量填写、测试运行和结果保存。

### 2.3 提示词实测排行榜（可随时刷新）
- 提供“立即刷新”操作，并可配置定时刷新；刷新排行榜不自动改动正式提示词。
- 排名维度：综合、小说分析、剧本、人物一致性、图片、分镜、视频、配音剪辑。
- 每条成绩记录提示词版本、测试素材/数据集版本、模型与参数、测试时间、评分明细、失败样本和人工复核结果。
- 默认使用同一测试素材、相同模型和参数进行 A/B 对比；条件不一致时必须标注，不得直接当作严格可比成绩。
- 评分维度至少包括：剧情完整与连贯、人物一致性、可执行性、镜头表达、画面质量、连续性、返工率；权重可配置并显示计算口径。
- 区分“自动评估分”“人工复核分”“发布后实际表现”，不得混为一个分数。
- 排行榜保存每次快照，可查看排名变化、历史成绩、版本差异和回滚目标。
- 允许随时增加测试样本和重新测试；旧成绩保留，不静默覆盖。

### 2.4 正式提示词更新门禁
- 热门研究或排行榜只能生成“升级候选”，不得自动替换正式提示词。
- 候选必须展示旧版/新版差异、修改原因、证据来源、测试结果、潜在风险和预期改善。
- 用户明确点击确认后才能发布为正式版本；拒绝或未操作时正式库保持原样。
- 每次发布保留不可覆盖的版本历史，支持对比、恢复和重新测试。

## 3. 长篇小说一键批量漫剧生产

- 支持导入整本小说并建立章节索引、人物关系、世界观、地点、时间线、伏笔和剧情主线。
- 先分析全书，再规划卷/季/集；集数不固定，可扩展至数百集，用户可指定单集时长和节奏。
- 自动生成分集大纲、剧本、角色表、场景表、分镜、图片/视频任务、配音字幕和剪辑合成任务。
- 角色外观、服装、年龄、伤势、道具和关系状态按剧情时间线维护；用户确认的角色设定作为一致性基准。
- 每集、每镜头均可单独重做；失败任务进入队列，不影响其他已完成结果。
- 提供全书进度、分卷进度、单集进度、资源占用、磁盘空间预估和预计任务量。
- 针对 16GB 内存和集成显卡采用串行/限流队列、分辨率分级、模型卸载与缓存回收；不得默认大量并行占满内存。
- 所有中间结果可断点续做；重新规划前明确提示受影响的下游数据，保留旧版本，不静默删除。

## 4. 全球发行与收益管理中心

- 国内外平台按地区、内容类型、格式要求、创作者资格、官方发布接口分类管理。
- 输出多语言标题、简介、标签、字幕、配音、封面和横竖屏版本；支持中文、英语、西班牙语、日语、韩语等。
- 只对官方 API 或已授权合作平台开放自动发布；其他平台仅生成上传包、发布清单和官方入口。
- 记录平台账号别名和授权状态；不保存明文密码，不模拟登录，不绕过验证码或平台限制。
- 收益按币种记录：预估、已确认、待结算、可提现、已提现、已到账、冻结、失败。
- 支持手动录入或导入平台对账单；展示平台分成、手续费、税费、汇率和净收入。
- 提现门槛、预计结算日、到账日期、失败原因和凭证均可追踪；具体规则以用户账号所在地区及平台当时官方规则为准。
- 软件不保管资金、不代用户提现、不自动绑定收款账户、不自动发起付款。

## 5. 验收标准

### 数据安全
- 升级前后现有小说、模型、素材、项目和用户配置数量/校验值一致。
- 新功能数据可备份、恢复、导出；删除操作必须二次确认。
- 断网时提示词库、历史排行榜、已下载项目与本地生产流程仍可使用。

### 提示词中心
- 新增、编辑、复制、删除、分类、搜索、导入/导出均通过测试。
- 手动刷新排行榜可生成新快照；历史快照可查看。
- 刷新排行榜不改变正式提示词版本。
- 未经用户确认无法发布候选；确认发布后可查看版本历史并回滚。
- 同素材 A/B 测试结果可复现，测试条件和评分依据完整可追溯。

### 长篇生产
- 使用同一测试小说验证全书分析、动态分集、剧本、分镜、角色一致性、断点续做和失败重试。
- 允许数百集规划；生产队列必须限流，不能因批量任务导致应用无响应或无提示地耗尽内存。
- 原文变更时暂停旧项目后续生产并保留旧成果。

### 全球发行与收益
- 未授权平台不得显示“自动发布成功”。
- 可生成平台适配上传包；收益和提现状态可手动录入、导出和核对。
- 多币种汇率、费用、税费和净额计算显示计算依据；未知数据不得编造。

### 发布门槛
- 完成自动化测试、Windows 离线安装器构建、安装/升级/卸载测试及目标电脑实机验收后，才可称为正式版完成。
- CPU/GPU 加速、视频生成能力、平台 API 覆盖率必须按实测结果说明，不得以界面存在代替功能完成。

## 6. 建议实施顺序

1. 先完成提示词中心的数据结构、用户自定义提示词、版本历史和本地持久化。
2. 完成同素材 A/B 实测、可随时刷新排行榜、历史快照和用户确认发布门禁。
3. 接入公开市场研究数据源、证据记录和候选提示词生成。
4. 扩展长篇全书分析、动态分集和受资源约束的批量生产队列。
5. 完善全球多语言发行、平台上传包和收益/提现台账。
6. 统一进行数据迁移保护、自动化测试、离线安装和 Windows 实机验收。

本规格是新增功能的开发与验收依据；实际完成状态必须以代码、自动化测试和 Windows 实机结果为准。
