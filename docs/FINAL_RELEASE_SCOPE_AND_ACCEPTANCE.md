# AI 漫剧制作大师：正式版功能冻结与最终验收标准

更新日期：2026-11-22  
开发分支：`feat/product-completion-foundation`  
当前交付策略：只交付正式版；开发期间不向用户提供测试安装包。

## 1. 本次交付承诺

本文件记录用户已确认的本次完整范围。目标是让不懂 AI、不会剪辑、不会写分镜的新手，能够通过中文向导完成从小说导入到漫剧成片导出的完整流程。

“功能完成”必须同时满足：实现代码、前后端/桌面端接通、用户界面可操作、失败路径可恢复、自动化测试覆盖、使用说明更新。仅有 API、静态界面、模拟结果或文档说明均不算完成。

## 2. 六大核心阶段

1. **图片生成系统**：模型目录与许可审核、模型管理、文生图、图生图、批量生成、角色一致性、硬件适配与生成结果归档。
2. **剧本与分镜系统**：小说导入解析、剧情改编、自动分集、镜头拆分、分镜编辑、人物/场景/道具关联及剧情连续性检查。
3. **视频生成与剪辑**：本地视频生成链路、供应商适配器、参考图输入、镜头衔接、多轨时间轴、转场、片头片尾和成片合成。
4. **配音、字幕和音效**：多角色声音档案、试听、配音、字幕翻译与校验、背景音乐、音效、时间轴同步及可选口型同步能力探测。
5. **全软件整合与修复**：前后端和桌面端整合、统一任务中心、进度与取消、异常恢复、项目备份、版本管理、数据隔离和完整回归。
6. **离线安装包与最终验收**：引擎、许可通过的必要模型、依赖、安装/卸载、首次启动、断网核心流程、数据保护、校验和及正式版交付。

## 3. 已确认的新手体验功能（10 项）

- 新手教学：首次启动向导、分步骤说明、功能解释、常见问题。
- 漫剧模板中心：热血、玄幻、仙侠、都市、校园、悬疑、科幻、恋爱等可编辑模板。
- 角色资产中心：角色外貌、服装、发型、声音、性格、参考图和版本跨集复用。
- 生成前预览：正式生成前预览剧本、分镜、角色、场景和配音。
- 版本管理：剧本、分镜、素材和时间轴的版本对比、撤销和恢复。
- 智能资源管理：磁盘、内存、模型占用检查和安全清理。
- 多平台输出：横屏、竖屏、方屏及常用分辨率/帧率预设。
- 制作资源统计：生成次数、耗时、存储占用、模型使用和收费提示。
- 项目备份迁移：备份、恢复、导入、导出和换机迁移。
- 简易/专业模式：简易模式隐藏复杂参数，专业模式提供高级控制。

## 4. 已确认的底层保障功能（3 项）

- 版权与授权检查：模型、字体、音乐、音效、代码依赖逐项核查；无法确认可再分发的内容不得打包。
- 离线完整性检查：检查引擎、模型、依赖、版本和哈希；核心本地能力不得静默回退到云端。
- 自动故障诊断：本地日志、错误分类、中文修复建议；默认不上传素材、密钥或项目正文。

## 5. 已确认的制作增强功能（8 项）

- AI 智能审片：检查黑帧、静音、字幕问题、音画同步、异常片段并给出可复核报告。
- 单镜头重新生成/替换：尽可能只重做问题镜头，保留旧版本和原始素材。
- 剧情连续性检查：核对人物设定、服装、场景、时间和剧情状态。
- 多角色配音试听：试听角色音色，调整语速/音调；中文语音可用性需实机验证。
- 素材搜索去重：按名称、标签、类型、项目和相似文件查找，重复项先提示不自动删除。
- 批量制作排队：多集任务排队、进度查看、失败恢复和防重复提交。
- 片头片尾水印：模板、署名、水印位置和透明度可配置。
- 项目交付包：成片、字幕、封面、剧本、素材清单和项目元数据整理导出。

## 6. 统一验收门槛

### A. 新手完整流程
- 新用户无需阅读开发文档即可创建项目、导入小说、选择模板并完成引导。
- 能从小说一路完成剧情分析、角色/场景确认、分集、分镜、图片/视频、配音字幕、剪辑、审片和导出。
- 每一步明确显示当前项目/分集、所需输入、进度、下一步和失败处理方式。
- 默认参数可用；高级参数不阻断简易模式。
- 允许只重做单个镜头或替换单个素材，不要求整集返工。

### B. 费用、隐私和离线
- 不自动充值、购买、订阅或调用未知计费服务。
- 任何收费或费用未知的第三方操作必须先显示说明并取得明确授权。
- 本地优先；没有用户授权不得将小说、图片、视频、音频或项目文件上传第三方。
- 不自动云端回退；网络开关关闭时必须保持本地功能边界清晰。
- 用户数据和模型目录在升级、卸载、失败恢复时得到保护。

### C. 硬件适配
- 目标设备基线：AMD Ryzen 7 4800U + Radeon 集成显卡。
- 必须识别集成显卡，不得误报独立 AMD GPU 或承诺未实测的 GPU 加速。
- 支持 CPU 兜底、内存/磁盘预检、低资源设置和任务排队。
- 在目标设备完成实际模型推理、长时间运行、导出和温度/资源观察后，才能标记为该设备实测通过。

### D. 自动化与实机测试
- 单元测试、API 集成测试、前端 TypeScript/生产构建、Windows 安装构建和卸载数据保护检查全部通过。
- 测试必须覆盖异常、取消、重复提交、断网、损坏文件、跨项目素材和数据库迁移恢复。
- Windows 实机验证：全新安装、首次启动、路径含中文/空格、非管理员运行、重启恢复、卸载保留数据、重新安装。
- 断网实测：启动软件、打开项目、编辑本地内容、运行已安装的本地模型能力、剪辑和导出。
- 完整离线包必须实际生成、逐文件核验、校验和验证，并在干净 Windows 环境安装；CI 的轻量安装构建不能代替此项。

## 7. 设备、引擎和模型的明确限制

- **ComfyUI 本阶段不升级。** 不更改现有 ComfyUI 版本、插件、工作流、模型或用户配置。
- ComfyUI、PyTorch、CUDA/ROCm/XPU、Ollama、模型和压缩工具的准确版本及许可证必须按最终实际归档逐项审查。
- Qwen3 4B 的离线模型清单、manifest、blob SHA-256 和模型许可需有可验证证据。
- Stable Diffusion 1.5 FP16 当前仍是待审核候选，不得在许可、哈希和目标设备测试通过前纳入可分发离线包。
- 口型同步和额外视频供应商能力必须以许可通过的实际模型/官方接口和实测为准；无法实测时清楚标记为未启用，不伪装成可用。
- 完整离线包预计体积较大，必须支持可靠下载、分卷/镜像和校验恢复；不得把不完整的 Setup.exe 当作完整离线正式版。

## 8. 正式交付状态定义

每项功能只允许使用以下状态，不得混淆：

1. **未开始**：尚无实现。
2. **开发中**：有代码但尚未完成端到端流程。
3. **自动化测试通过**：相关测试和 CI 已通过。
4. **本地引擎实测通过**：真实本地引擎/模型运行通过。
5. **目标设备实测通过**：在 Ryzen 7 4800U 目标设备验证通过。
6. **正式包验收通过**：完整离线正式包在干净 Windows 环境安装、断网使用、卸载/重装数据保护通过。

未取得相应证据，不得将功能标记为更高状态。

## 9. 当前已知正式交付阻断项

- ComfyUI portable 全部变体的逐文件依赖清单和再分发许可审查尚未完成。
- Ollama Windows runtime 的完整依赖许可清单尚未完成。
- Qwen3 4B 模型 manifest/blob 哈希与最终归档证据尚待核验。
- Stable Diffusion 1.5 FP16 的精确版本许可、哈希和目标设备 CPU 实测尚未完成。
- 完整离线安装 payload 尚未生成并在干净 Windows 环境验证。
- Ryzen 7 4800U 目标设备真实推理和长时间稳定性尚未实测。
- 最终正式版安装、断网使用、卸载保留数据和重装流程尚未由用户设备验收。

这些阻断项不会通过删除安全检查或降低标准来“变绿”。在全部正式交付门槛满足前，不生成或宣传可供最终验收的正式安装包。

## 10. 发布纪律

- 开发期间统一提交到开发分支和 Draft PR。
- 不合并 PR、不发布 GitHub Release、不向用户发放测试安装包，除非用户另行明确要求。
- 仅在六大阶段、已确认的 10+3+8 项功能及全部验收门槛完成后，才准备正式版下载。
- 最终交付同时提供版本号、安装包、SHA-256、离线资源说明、安装/卸载说明、已知限制和逐项验收报告。
