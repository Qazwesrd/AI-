# AI漫剧制作大师

全新 Windows 桌面 AI 创作平台。

## 核心功能
1. 小说智能解析
2. 人物、场景、道具识别
3. AI三维视觉素材生成
4. AI剧本改编
5. AI智能分镜
6. AI漫剧视频生成
7. 自动视频合成
8. AI智能视频剪辑
9. 多AI模型管理
10. 免费额度及付费确认

## 技术架构
- Electron
- Next.js
- React
- Python FastAPI
- SQLite
- FFmpeg

## 项目目录
- apps/desktop：桌面程序
- apps/web：前端
- apps/api：后端
- packages：共享功能
- storage：本地素材
- docs：项目文档
- scripts：自动化脚本
